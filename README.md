# Mi Proyecto SAP: Extensión para Sourcing & Procurement

## 🌟 Descripción del Proyecto
Este proyecto demuestra mis habilidades en desarrollo ABAP Cloud para SAP S/4HANA, enfocado en el área de Sourcing & Procurement. Incluye la implementación de un Business Add-In (BAdI) siguiendo las mejores prácticas de ABAP Cloud.

## 🛠️ Tecnologías y Herramientas
- **Entorno:** ABAP Cloud (SAP S/4HANA Cloud Trial en contenedor Docker)
- **IDE:** ABAP Development Tools (ADT) para Eclipse
- **Lenguaje:** ABAP (Cloud Development Model)
- **Control de Versiones:** abapGit + GitHub
- **Sistema Operativo:** Debian GNU/Linux
